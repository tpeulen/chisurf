# Each entry carries the route it takes, decided 2026-10-05 (owner: tpeulen):
#
#   numpy     -- numpy 2.x already has it (trapezoid, normal, eig, interp);
#                delete the import and rename. Zero new code.
#   local     -- small, correctness-first reimplementation inside chisurf
#                (chisurf/core/math/special.py + per-site helpers). Cold or
#                once-per-fit paths only.
#   bff       -- performance-relevant numerics go into IMP.bff's C++ core
#                (optimizers around FitMinimizer, hot special functions,
#                the ODE integrator) and are re-exposed through a thin
#                Python shim in chisurf.
#   tttrlib   -- image and spatial kernels go into tttrlib (filters next to
#                the tested C++ rank_filters/fast-gaussian, clustering next
#                to hdbscan/kmeans/kdtree, assignment next to kmeans).
#                Everything landing there is browser-ready via PRD-041's
#                wasm wheel.
#   legacy-io -- scipy.io MAT-file readers/writers. Superseded 2026-10-06
#                (owner: scipy leaves; curves I/O -> tttrlib): tttrlib.matfile
#                reads/writes Level-5 MAT-files like scipy.io; none remain.
#
# Mixed files (one scipy call each to bff/tttrlib/local) carry a comment
# naming the split. Two YAML files embed scipy calls in text and are NOT
# scanned by this seam (see the traps in okf/subsystems/scipy-retirement.md):

# the work up.
