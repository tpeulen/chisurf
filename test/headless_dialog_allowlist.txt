# It is empty, and meant to stay that way. A raw box spins its own event loop
# until a button is pressed: under QT_QPA_PLATFORM=offscreen nobody can press
# one, so the error is never reported and the run never ends — and the answer a
# question box never gets is the one deciding whether a file is overwritten.
#
# chisurf.gui.dialogs logs unconditionally, shows the box only when a person is
# there to close it, and otherwise returns the caller-declared safe default.
