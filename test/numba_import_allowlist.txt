# numba is being retired from the shipped package. Never add yourself here to
# make test/test_numba_seam.py pass -- port the kernel and strike the line.
# The end state is an empty list, after which numba leaves the manifests and
# joins RETIRED in test/test_no_retired_dependency_imports.py.
#
# ChiMOL is not on this list and is not scanned: its kernels are being removed
# by the WebGPU port, a separate effort with its own tracking.
#
# Each entry carries the route it takes, because "port it" means four
# different things here and picking the wrong one is how a fast kernel becomes
# a slow one:
#
#   numpy   -- delete the decorator. The kernel is elementwise, dead, or small
#              enough that numba's dispatcher costs more than the kernel does.
#              Measured: numba/core/types/abstract.py:__hash__ lands in the
#              top-14 of a FRET fit profile while these kernels are ~4% of it.
#   tttrlib -- a compiled equivalent already ships in tttrlib 0.27.0. Delegate;
#              write no new code.
#   imp     -- molecular modelling that already migrated to imp-tricks and was
#              left behind here. Delete the copy, import IMP.bff / IMP.cgmol.
#   tttr-c  -- genuinely serial and genuinely hot, with no equivalent yet.
#              Needs a new kernel in tttrlib's modules/math.
#   wgsl    -- large uniform 3-D grid, one-shot, independent per voxel. Goes to
#              a WGSL compute shader via chisurf/core/gpu (and retires the dead
#              pyopencl path with it).
#
# See okf/subsystems/numba-retirement.md for the full routing, the measurements
# behind it, and where to pick the work up.
