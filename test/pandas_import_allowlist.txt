# This is a SHRINKING list and a tracker: 47 non-test files when it was
# written, 24 now. It is not somewhere to add yourself. pandas is an interop format here
# -- a frame handed to a notebook, or a file only it can read -- not the storage
# model; the storage model is the columnar store behind chisurf.core.datastore.
#
# Enforced by test/test_pandas_seam.py, which fails on a new importer AND on a
# stale entry, so the count keeps meaning something.
#
# Removing pandas from the CODE does not remove the package from a solved
# environment: the conda pdb2pqr requires pandas >=1.0 outright, as do
# seaborn-base and statsmodels. What it wins is that ChiSurf's own tables stop
# being frames -- half the memory, dtypes that survive a file, and a missing
# value that does not have to be a NaN.
