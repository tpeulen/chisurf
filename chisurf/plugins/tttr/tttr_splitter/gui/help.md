# Tttr Splitter

## Load input
Pick the photon stream to split in the **Input** table: the TTTR files and container streams of the Datasets workspace (files enter ChiSurf by dropping them on the ChiSurf window; *Open in…* on a dataset, or dragging it onto this window, does the same). A container's stream is never cut out of its container, whatever *Keep original* says.

## Choose formats
Select the input container and desired output container.

## Set split options
Choose the chunk size and binning. Disable Split into files for a single output. Keep original protects the source.

## Convert or split
Choose an output folder, then run. The written files appear in the workspace under their input. Batch uses the same settings: select PTU streams in the batch's own **Input** table and press **Use selected** to queue them.

## Panels
Right-click a dock header to close, reopen, undock, or restore the default layout.
