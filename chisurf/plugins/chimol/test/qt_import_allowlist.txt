# Modules that still import Qt. SHRINKING -- never add a line.
#
# chimol runs in three hosts and only one of them has Qt: the plugin. The other
# two are a GLFW window and a browser canvas, and a module that imports Qt is a
# module they cannot use.
#
# `app/*` and `renderer/wgpu_view.py` are the embedding window and are expected
# to stay. `cmtk/qt_painter.py` and `host/qt_overlay.py` are the
# QPainter half of the painter seam; `cmtk/qt_host.py` hosts a
# painter-level control inside a real QWidget (imported lazily, inside its
# constructor, same reason as qt_painter.py) and is the seam AutoForm's
# `code_editor`/`memory_editor` custom sections embed a chimol control
# through. `host/widget.py` is the seam that decides whether Qt is used at
# all. `cmd/exporting.py` and `cmd/inspect.py` are commands that open a Qt
# dialog/window as an explicit, guarded (`try/except ImportError`), opt-in
# convenience -- typing the command still works with no Qt binding present.
# Everything else here is a leak.
