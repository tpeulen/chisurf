# Structure Tools

One window for the tools that prepare and check structures for FRET modelling.

## The tools

| Tool | Use it to |
|---|---|
| FPS JSON Editor | Edit `fps.json` files for accessible-volume modelling and fetch reference PDBs. |
| Docking & Screening | FRET-restrained rigid-body docking, refinement and library screening. |
| QuEst | Simulate dye diffusion and quenching and predict the fluorescence decay. |
| HydroPro | Run HYDROPRO / HYDRO++ hydrodynamic calculations. |
| Trajectory Tools | Align, convert, join and clean trajectories. |

## Moving around

Select a tool in the list; the search box narrows the list by name or description, and **Back** / **Next** step through it. Each tool keeps its settings and results while another is shown, and has its own **Guide** and **Help** buttons.
