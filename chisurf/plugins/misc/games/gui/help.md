# Games

Five small games, one window.

| Game | Keys |
|---|---|
| Number Quest | Arrows dial, Q/E change by 10, Enter submits, R or Esc starts a new round |
| Minesweeper | Arrows move, Enter scans, F flags, Q/E change the board size |
| Tetris | Left/Right move, Up rotates, Space drops, P pauses |
| Pong | Up/Down paddle, W/S second player, P pauses, M changes mode |
| Breakout | Left/Right paddle, Space launches, P pauses |

## Moving around

Select a game in the list, or press **1** to **5**; **Tab** goes to the next one. Each game keeps its state while another is shown, and mutes its sound whenever this window is not in front. M toggles sound or mode in each game, R or Esc resets it.
