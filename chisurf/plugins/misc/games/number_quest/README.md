Number Quest can run independently through `emtk.native --app chisurf.plugins.misc.games.number_quest.app:make_app`. The native factory imports no Qt modules. The original Qt widget remains available.

The native view uses the unchanged `NumberQuestGame` rules: seven guesses, 1–100 range, score and longer/shorter hints. Arrow keys or A/D dial one unit; Q/E dial ten; Enter/Space submits and confirms a completed round; R restarts. Held keys repeat after 280 ms, then every 45 ms. Clicking the decay plot selects an estimate. Footer captions submit/restart by mouse. Settings preserve target, history, estimate, and the sound preference; restoration replays rules and validates the complete state before replacing the live round. Focus loss releases held inputs, and closing stops updates and closes an injected audio backend.

Labels and tooltips are available in English, German, French, Spanish, Portuguese, and Russian. The original bitmap face is retained in plugin-owned glyph data; characters outside ASCII use EMTK's Unicode font.

Audio limitation: EMTK supplies no standalone equivalent of chigame's tracker/GPU audio host. Native default audio is silent; an injected compatible backend can receive the original guess effect and sound toggle. No platform audio dependency was added. Native music is not reproduced.

Visual references and native captures are generated by `test.capture_qt` and `test.capture_native`, using populated deterministic rounds (target 37, guesses 50 and 25, current estimate 37).
