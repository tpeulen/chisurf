# Help Browser

Browse the ChiSurf documentation: table of contents and search on the left,
the page on the right, an assistant that answers from the docs in the Ask
pane. Ctrl is Command on a Mac.

## Keyboard shortcuts

Every shortcut calls what the matching button calls; the button tooltip names it.

| Shortcut | Action | Button |
|---|---|---|
| Ctrl+F | Move the keyboard to the search field | search field |
| Alt+Left | Back in the navigation history | Back |
| Alt+Right | Forward in the navigation history | Fwd |
| Alt+Home | Show the documentation start page | Home |
| Ctrl+Shift+A | Bring the Ask Docs pane to the front | Ask Docs tab |
| Ctrl+= or Ctrl++ | Larger document text | A+ |
| Ctrl+- | Smaller document text | A- |
| Ctrl+0 | Restore the application font size | Reset zoom |
| Ctrl+wheel or Shift+wheel | Zoom the document text (Shift+wheel for trackpads, where the system takes Ctrl+scroll) | A- / A+ |

## Reading a page

The text column is at most about 860 pixels wide and centred, so a line stays readable in a
maximised window; it narrows with the window. A figure narrower than the column is enlarged to
fill it (never past twice its own pixels). Click a figure to open it at full size: **Fit to window**
shows it whole, **Actual size** at its own pixels, **Zoom in** / **Zoom out** magnify.

## Ask Docs

The empty pane says what the assistant is for and offers example questions. It only reads
documentation; it cannot load data or run a fit. Each answer ends with the pages it was read
from, as links; a page path the answer names becomes a link when the page exists. An answer for
which no page was opened says so: treat it as a suggestion. A failure (no provider, no key) is
shown with its reason.
