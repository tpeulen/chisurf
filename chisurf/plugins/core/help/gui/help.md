# Help Browser

Browse the ChiSurf documentation: table of contents and search on the left,
the page on the right, an assistant that answers from the docs in the Ask
pane. Ctrl is Command on a Mac.

## Keyboard shortcuts

Every shortcut calls what the matching button calls; the button tooltip names it.

| Shortcut | Action | Button |
|---|---|---|
| Ctrl+F | Move the keyboard to the search field | search field |
| Alt+Left | Back in the navigation history | Back |
| Alt+Right | Forward in the navigation history | Fwd |
| Alt+Home | Show the documentation start page | Home |
| Ctrl+Shift+A | Bring the Ask Docs pane to the front | Ask Docs tab |
| Ctrl+= or Ctrl++ | Larger document text | A+ |
| Ctrl+- | Smaller document text | A- |
| Ctrl+0 | Restore the application font size | Reset zoom |
| Ctrl+wheel | Zoom the document text | A- / A+ |
