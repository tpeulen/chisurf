# The bounds transform must not stall on decade-spanning bounds

# Why

Found 2026-09-02 writing the ICS recovery test (recorded in
[known-issues](../references/known-issues.md)): with `bounds_on=True` and
the parameter groups' defensive defaults (`ub=1e9`, widths to `1e5`), a
2D-Gaussian fit from a *close* start stops at chi2r ≈ 600 where the
unbounded problem converges to chi2r ≈ 1.0 in six evaluations. Graph and
director stall **identically** — it is the shared sin/sqrt-style
reparameterisation, whose Jacobian columns for a huge interval sit
kilometres from the others' scale. Any bounded fit with wide bounds can
silently under-converge; the fit *finishes*, which is what makes it
dangerous.

# The job

1. Reproduce minimally in `imp.bff` (the ICS fixture from
   `test/fitting/test_graph_fit_ics.py` transplants directly), then
   instrument: is it transform curvature, MINPACK's relative step under
   the transform, or diagonal scaling?
2. Fix in the engine's bound handling — candidates, in order of
   preference: (a) projected/clipped steps instead of a smooth transform
   (what scipy's `trf` does); (b) per-parameter step scaling aware of the
   transform's local derivative; (c) internal rescaling of the transform
   to the start value's decade. One implementation, both paths inherit it.
3. Re-run the ICS 2D-Gaussian recovery **with bounds on** and the DEER /
   TCSPC / FCS graph suites (answers must not move on well-posed fits).

# Definition of done

- [ ] The ICS 2D-Gaussian fixture converges to chi2r ≈ 1 with the group's
      own default bounds (`bounds_on=True`), on both paths.
- [ ] `test/fitting/test_graph_fit_ics.py` drops its bounds-off
      workaround (the comment names this PRD; delete both together).
- [ ] All existing graph-fit answer-pinning tests unchanged.
- [ ] known-issues entry struck.

# Traps

- The bounded reference behaviour is pinned by
  `test_bounds_are_honoured` — bounds must still bind exactly, only the
  path to the interior minimum may change.
- `reference_leastsqbound.py` (imp.bff test/) is the frozen historical
  transform: parity against it is *not* a goal here — this PRD exists
  because that transform's behaviour is the defect.
