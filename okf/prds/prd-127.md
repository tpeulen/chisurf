# PDA algebra dedup

# Why

Phase-4 register row. The sharpest case is `pch/pch.convolve_pch`: a
Python self-convolution *in the same file* as the `tttrlib.pch_*` calls —
the two-implementations-in-one-file shape that disagrees silently.
`mfd/histogram.py` re-implements binomial/Poisson PDA beside
`tttrlib.Pda`; `pda3c/likelihood.burst_log_likelihood_reference`
duplicates `PdaBurstLikelihood`.

# The job

1. Per copy, decide *forwarder* or *frozen reference*: a reference used
   only by a parity test moves into `test/` with the frozen-reference
   naming (the `_quickfit_reference` transcription in
   `test/models/test_fcs_maxent_engine.py` is the template); a live path
   forwards.
2. Parity A/B before each change — PDA is where the S1S2 cache defect hid
   (6× per residual, found 2026-09-02); assert on realistic n_max, not
   toy sizes.
3. `burst_log_likelihood_reference`: if it is already test-only, this row
   is a *move and rename*, not a port — check callers first.

# Definition of done

- [ ] No live chisurf path computes PDA/PCH algebra the engine ships;
      each former copy is a forwarder or lives in `test/` as a named
      frozen reference.
- [ ] Parity pinned per forwarder at realistic sizes.
- [ ] Register row struck in [PRD-105](prd-105.md).
