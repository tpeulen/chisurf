# Shared native game help and restart surface

native host. Preserve them; turn-based games need no synthetic pause model.
Add one shared AutoForm button row in the existing free top strip. GameApp owns
Help, Restart and Guide through the existing form, help-window and tour APIs.
Preserve Sound, canvas coordinates, rules, status and existing reset behavior.
Minesweeper has no header subtraction; measure all three board difficulties.
The Games hub must preserve child controls and their coordinate offsets.

apps and interaction tests. A separate resource owner writes five help pages and
five tours. The games generate playable rounds; no external demo serialization
is needed. Root owns integration, visual inspection, catalogs, documentation,
guards, one evidence archive and local publication. Exact HEAD-derived candidates
preserve foreign bindings and edits.

## Before reference and acceptance

those exact states for the after pair rather than regenerate an unseeded board.

as well as inside it; tour controls remain usable only as intentionally awaited.
Check actual clicks, tooltip hover, overlay departure, six locales at narrow
widths, all minefields and embedded hub coordinates. Compare complete old paint
commands and exported states, excluding the intentional new row and overlays.
