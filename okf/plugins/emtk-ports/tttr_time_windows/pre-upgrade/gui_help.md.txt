# Tttr Time Windows

## Queue files
Add supported TTTR files, a folder, or datasets from MMFDB.

## Choose duration
Set the duration in milliseconds; the preview boundaries update.

## Choose output
Leave empty for an automatically chosen output folder.

## Process
Write one BST file per input with inclusive photon boundaries.

## Panels
Right-click a dock header to close, reopen, undock, or restore the default layout.
