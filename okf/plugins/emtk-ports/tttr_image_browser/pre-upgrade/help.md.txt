# TTTR Image Browser

Configure a detector setup or receive one from Imaging Tools. The shared native editor supports routing channels, microtime/PIE windows, timing/TAC calibration and optical configuration. Continue to the browser and open/drop a folder; include subfolders when required.

Select images to reconstruct detector mosaics in the background. Filter by names or star rating, persist ratings and annotations, and enable multiple selection for batch exports. Copy preserves recursive paths. TIFF keeps physical intensity stacks; DOCX includes mosaics, ratings and notes. Clear caches removes only browser-generated caches.

Next hands the current source to an attached native imaging coordinator, switches to Intensity and starts it. Standalone browsing and all exports work without a coordinator.
