Reference
=========

Reference material: supported file formats, global settings, the complete plugin
catalogue (every plugin and every parameter), parameter linking, user-defined
models, and the headless CLI.

It also holds the three **registers** of the documentation itself — every
:doc:`figure <figures>` with its origin, every :doc:`table <tables>`, and every
:doc:`code block <code>` with the verification it is subject to. They exist so
the documentation can be *refreshed* rather than rewritten: see
:doc:`/development/documentation_maintenance`.
