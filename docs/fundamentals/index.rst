Fundamentals (photophysics)
===========================

Reference for the physics the analyses assume: the excited state, its
orientation and coupling, the probe, and the measurement chain. One page per
topic, formulas and definitions first.

   :header-rows: 1
   :widths: 22 78

   * - Layer
     - Question
   * - **Fundamentals**

   * - :doc:`Guides </guides/index>`
     - Which control, in which order?
   * - :doc:`Reference </reference/index>`
     - What is the exact name, format, default?
