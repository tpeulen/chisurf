# Application identity and support details

About ChiSurf identifies the running application through its name, version,
developer, contact and repository. A development version distinguishes builds;
it does not validate a scientific result or describe a measurement's provenance.
Reproducing an analysis also needs its inputs, method, settings and outputs.

Copy details exports only those displayed application fields to the host's
clipboard. It includes no measurement, filename, fit result, credential or user
setting. The user decides where to paste it and which reproduction steps to add.
A clipboard failure leaves the guided action pending rather than claiming a copy.

Help explains the fields; the guide waits for Help, Copy details and Close.
Close ends this information window and its tour while the main application
remains available. See the [application-information workflow](../guides/103_application_identity.md).
