Concepts (theory)
=================

These pages explain the **theory** behind each analysis ChiSurf performs — what
the models mean, which assumptions they make, and how their parameters map onto
physical quantities. They are self-contained and cited, and each links to the
:doc:`guide </guides/index>` that shows how to run the analysis in ChiSurf.

The concept pages summarize and adapt the durable knowledge captured in the
project's Open Knowledge Format (OKF) bundle (``okf/references/``), which is the
maintained source of the theory layer.
