# Loading the data: Defining the reading parameter

ChiSurf supports a variety of experiment types (TCSPC, FCS, Modelling) and file formats (e.g. txt or csv, tttr, sdt,...) it is vital to define the correct reading parameter.

Here, our *experiment* is "TCSPC" and the *File Type* is "TXT/CSV".
