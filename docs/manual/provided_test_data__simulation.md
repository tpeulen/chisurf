# Provided test data – simulation

**Settings / Assumptions:**

1. Bimodal diffusion: 30 % of the molecules diffuse fast (*tD1* = 1 ms) and the rest slowly (*tD2* = 100 ms), as stated in {doc}`simulation_details`
2. Dynamic exchange between two equally populated FRET states, high FRET (HF; FRET efficiency *E* = 0.7) and low FRET (LF, with *E* = 0.2), with a time constant of *tR* = 70 µs
3. Additionally, 16 % of triplet blinking at 5.5 µs was added.
