Reference curves
""""""""""""""""

.. image:: _images/image_rId31.png
  :align: center

:strong:`Fig.24 FRET model fit plots.` (a) The fluorescence decay of the donor in the presence of an acceptor, :math:`f_{D(A)}(t)`, can be plotted against the decay of the donor in the absence of an acceptor, :math:`f_{D(0)}(t)`, as a reference. Enabling the "Use reference" checkbox displays the ratio :math:`f_{D(A)}(t) / f_{D(0)}(t)` — the FRET-induced donor decay, which isolates the transfer from everything the donor does on its own. (b) FRET models can be displayed as distance distribution, FRET rate constant distribution of as fluorescence lifetime distribution. Fluorescence lifetime distributions can adopt more complex shapes for multi exponential donor fluorophores.

The option is in the plot settings of a FRET model (see :strong:`Fig.18` and :strong:`Fig.24`). A reference curve is only meaningful when the two decays were measured under the same conditions — same IRF, same time axis, same background — because the ratio divides those out only if they are identical.
