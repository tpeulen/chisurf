# Calibration of detection volume – red excitation

For the red detection volume, we proceed as described for the green detection volume.

Only the fit results will be provided for a guidance.

Important: Use the correlated signal of the directly excited red fluorophore within the delay time window of your measurement, e. g. "**A568_ACF_delay.cor**"
