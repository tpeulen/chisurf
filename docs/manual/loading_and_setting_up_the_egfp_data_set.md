# Loading and setting up the eGFP data set

Repeat all steps from above with the eGFP data set. Once completed, six windows should be present in
ChiSurf.

```{image} figures/anisotropy_two_samples.png
:align: center
```

Six fit windows after **Tile Windows**: the three of the first sample (bottom row, fitted) and the three
the wizard created for the second (top row, not yet fitted). The second sample shown is the bundled
9 ps recording of `test/data/tcspc/Jordi`, standing in for eGFP.

Note that as initial parameter for eGFP two lifetimes of 1.3 and 2.6 ns (~ 30:70) should be given, and a single rotational correlation time of 15 ns.
